Privacy policy

Boardroom Files uploader. Last updated 29 October 2026.

Who uses it

Boardroom Files uploader is a private tool. Its only user is the owner of the Boardroom Files YouTube channel, who uses it to upload that channel's own videos.

What it accesses

With the owner's permission, granted through Google's sign-in, the tool uses the YouTube Data API to upload videos, set their thumbnails and add captions on the owner's own channel. It requests only the scopes needed for this: youtube.upload and youtube.force-ssl.

What it stores

The access credential Google issues is stored as an encrypted secret in the owner's private code repository so the uploads can run automatically. No other personal data is collected, stored, sold or shared, and no data from any other Google user is accessed.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions.

Contact

Through the Boardroom Files channel on YouTube: youtube.com/@BoardroomFiles-TV.
